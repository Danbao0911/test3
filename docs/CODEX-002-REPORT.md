## 已实现

- ADMIN、REVIEWER、VIEWER：来源策略仅管理员可改；审核员可录入/提取/核验；只读成员不能写入，联系列表和详情均使用白名单 DTO，隐藏原值、规范值、证据正文、证据地址、字段位置、审核原因。
- 来源独立的 allowExtract / allowEvidenceText、有效天数、策略版本和操作人；能力默认关闭。仅批准账号录入并不能处理联系值。
- 五种规则字段：商务邮箱、明确商务微信、企业电话、官网联系页、预约链接。标签不明确、格式不符、缺失或第三方上下文返回零候选，不猜测。无网页抓取、拨号、邮箱发送验证或外部模型调用。
- 每条候选有独立最小证据片段（最多 300 字）、字段定位、来源 HTTPS 地址、取得时间和策略版本。完整输入不存储。请求流上限 32 KiB、文本 5000 字、最多 20 项。
- 待审核 → 通过/驳回/失效，批准须同时确认归属及商务用途。已驳回/失效不能直接恢复。历史记录包括操作人、决定、原因、时间和版本。
- 相同账号/来源版本/类型/规范值精确去重，重复提取不重建候选，不复活驳回项；不同账号不因共享公司邮箱合并。
- 来源行锁与来源修改共用；审核额外锁联系项并校验版本。并发审核一个成功、一个 409，不覆盖另一审核结果。读取/批准时重新计算来源、策略及期限，旧批准状态不等于当前可用。
- 最小化审计仅存 actor/action/target/time，不复制联系值、原文或审核原因。
- 中文来源策略表单、账号商务联系页、带分页及审核状态筛选的审核工作台、成员角色展示、受控命令行成员创建。

## 安全前置与范围限制

联系处理只开放隔离 demo/test 环境。生产提取和批准主动返回 403，原因是 T07 物理删除、抑制和到期清理尚未交付，不能提前接受真实联系人。

仅允许同一账号已登记来源；只支持可保存文本的证据。未获准保留文本的来源拒绝处理，不以哈希代替证据。演示候选仅接受示例域邮箱/链接、demo_ 微信、+1 202 555 01xx 电话；演示主页拒绝真实平台地址。既有数据库记录不自动改写或合并。

当前“有效天数”限制可用性，不代表已物理清理过期值。输入证据不会自动验证页面所有权；人工确认仍是必要步骤。规则较保守，未识别信息不等于不存在。联系失效/驳回当前不可逆，同一策略版本不会自动刷新过期证据；修正需新来源策略版本和新取得的证据。T05 工作台和 T06 关联审核已交付；尚无导出、后台删除/抑制任务或四平台真实采集，这些不在本次完成声明内。
